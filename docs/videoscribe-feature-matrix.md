# VideoScribe feature map and reconstruction targets

Reviewed 26 October 2026 against public official VideoScribe pages. Target: the current VideoScribe web/downloadable application, not VideoScribe Legacy. This is a documentation review, **not runtime verification or REA analysis evidence**. All implementation statements below are proposed design choices until verified in the local application.

## Evidence boundary

- **D — documented:** directly supported by a linked official help page.
- **I — implementation proposal:** an independent local implementation can supply this workflow; identical internal algorithms or visual output are not established.
- **G — dependency/gap:** a service, licensed content collection, or unavailable reference behavior needs separate provision and validation.

The [download page](https://www.videoscribe.co/download) describes the current installed version as the same product as the browser version, with synchronized projects, automatic updates, and no full offline mode. Legacy is maintenance-only. Rebuilding the current workflow therefore needs more than the old desktop draw-and-pan model.

## Proposed build sequence

1. **Reliable editor:** versioned project model, scene management, asset/text/shape editing, selection/transforms, camera frames, save/open and history.
2. **Shared animation engine:** deterministic scene/element/camera time sampling, vector strokes, raster/text reveal, entrance/emphasis/exit and transitions; preview and seek use identical calculations.
3. **Authoring precision:** storyboard and advanced timeline, stage durations, camera motions, alignment, import and original templates/assets.
4. **Audio and output:** actual imported/recorded audio, non-destructive edits, audio mixing and verified MP4/GIF exports, progress and cancellation.
5. **Optional connected capabilities:** real configurable AI providers, hosted previews and sync. Expose availability honestly when a provider is missing.

## Acceptance evidence required before claiming parity

- Save/open and reload preserve scenes, timing, camera positions, image/font/audio data and imports without network dependencies.
- Undo/redo covers scene, element, transform and timing changes; delete/duplicate/reorder retain coherent references.
- Drag/resize, zoom, pan and camera editing work at common desktop sizes; keyboard shortcuts do not intercept typing in text fields.
- Sample animation boundaries, loops, pauses, zero-duration stages, multiple scenes and camera interpolation; compare preview frames with exported frames.
- Export an actual 1080p multi-scene MP4 containing drawings, imported images, text, scene transition and audible mixed tracks; inspect dimensions, duration, codecs, representative frames and audio presence.
- Verify GIF animation, SVG safety, malformed project rejection, oversized imports, broken images/fonts, failed providers and export cancellation.
- Run physical microphone and subjective drawing-hand/animation/voice-quality checks separately. Passing build or synthetic tests does not establish those qualities.

## Unresolved reference details

Public documentation does not establish source code, renderer implementation, internal project format, exact easing/draw-path heuristics, backend export infrastructure, AI providers/models, account service APIs, or the licensing terms needed to redistribute the commercial asset collections. Runtime inspection may refine observable behavior; it cannot by itself grant access to those services or content.
