## FAQ

1. **Is Vibecraft free?** This local version is free to use. Opening the editor requires no account or payment.
2. **Where are my projects stored?** Projects are saved in this browser on this computer. Download a project file for backup or transfer.
3. **Can I use my own artwork?** Import supported SVG, PNG, JPEG, WebP and GIF files. Supported SVG geometry draws along its paths; other image content uses a reveal. GIF animation is currently a still frame.
4. **What can I export?** MP4, WebM and animated GIF, plus an editable project file. Video export uses FFmpeg installed on this computer.
5. **Can I add a voiceover or music?** Import audio, record a voiceover, use an installed Windows voice, or add the included original soundtrack. AI storyboard generation needs a locally installed Ollama model.
6. **Does it work on my phone?** The landing page works on small screens. The editor is designed for a desktop browser and a larger canvas.
